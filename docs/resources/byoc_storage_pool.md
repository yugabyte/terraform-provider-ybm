# ybm_byoc_storage_pool (Resource)

The resource to create a storage pool in a BYOC environment: a group of clusters, for example for a team or business unit. Create ybm_aeon_pg_byoc_cluster resources in it with storage_pool. Storage pools cannot be deleted, so destroying this resource only removes it from Terraform state; import the pool to manage it again.

~> **Note:** This resource is behind a feature flag. Set the environment variable `YBM_FF_AEON_PG=true` to use it.


A storage pool groups clusters in a BYOC environment, for example for a team or business unit. One environment can hold several. Creating a pool waits for the environment's agent to enroll, like `ybm_aeon_pg_byoc_cluster`. `owner_user_id` defaults to the account ID, as in the console. Creating a pool that already exists fails; import it instead.

!> **Warning:** Storage pools cannot be deleted, and the console treats them as undeletable. Destroying this resource only removes it from Terraform state; the pool stays in the environment, and you can import it again.

## Example Usage

```terraform
resource "ybm_byoc_storage_pool" "payments" {
  environment_id = ybm_byoc_environment.example.environment_id
  name           = "payments"

  # Install the environment's agent first; see the ybm_byoc_environment example
  depends_on = [helm_release.agent]
}
```

## Schema

### Required

- `environment_id` (String) The ID of the BYOC environment to create the storage pool in. Changing it forces a new storage pool.
- `name` (String) The name of the storage pool, unique within the environment. Changing it forces a new storage pool.

### Optional

- `owner_user_id` (String) The UUID of the pool's owner, which the environment's agent creates. Defaults to the account ID. Changing it forces a new storage pool.

### Read-Only

- `account_id` (String) The ID of the account the environment belongs to.
- `state` (String) The state the storage pool last reported.

## Import

Import is supported using the following syntax:

```shell
# A storage pool is imported by <environment_id>/<name>
terraform import ybm_byoc_storage_pool.payments acme-prod/payments
```
