# ybm_aeon_pg_branch (Resource)

The resource to create a branch of a PostgreSQL cluster: a copy-on-write fork of another branch with its own settings. Works for shared clusters (ybm_aeon_pg_cluster) and, with environment_id, BYOC clusters (ybm_aeon_pg_byoc_cluster). Connect to a branch through a ybm_aeon_pg_endpoint on it.

~> **Note:** This resource is behind a feature flag. Set the environment variable `YBM_FF_AEON_PG=true` to use it.


Set `environment_id` and `storage_pool` for a cluster in a BYOC environment; leave both unset for a shared cluster. Set `cluster_id` to the cluster resource's `cluster_id` so that replacing the cluster replaces the branch too.

`pg_settings` can be changed in place. They apply to every endpoint on the branch, and an endpoint's own `pg_settings` override them. Leave `pg_settings` unset to leave the settings as they are, including those a fork inherits from its parent; set it to `{}` to clear them. Removing a key resets the setting to the PostgreSQL default. `extensions` can be added in place but not removed, and the plan fails if one is. Changing `cluster_name`, `cluster_id`, `branch_name`, `parent_branch`, `fork_point_lsn`, `environment_id` or `storage_pool` replaces the branch, which deletes its data. The default `main` branch is created with the cluster and cannot be a `ybm_aeon_pg_branch`; set its settings with the cluster's `branch_pg_settings` and `branch_extensions`.

Deleting a branch also deletes its endpoints and the branches forked from it, so deleting a branch that still has any fails. A normal `terraform destroy` deletes the dependent resources first, so it works. To delete them along with the branch, for example to replace it after a `fork_point_lsn` change, set `force_destroy = true` and apply it first.

`ttl` is reserved for branch expiry, which is not supported yet, and setting it fails at plan time.

## Example Usage

```terraform
# A branch of a shared cluster, forked from main
resource "ybm_aeon_pg_branch" "dev" {
  cluster_name = ybm_aeon_pg_cluster.example.cluster_name
  cluster_id   = ybm_aeon_pg_cluster.example.cluster_id
  branch_name  = "dev"

  # Optional; both can be changed in place, and extensions can only be added
  pg_settings = {
    work_mem = "128MB"
  }
  extensions = ["vector"]
}

# A branch forked from another branch at a given LSN
resource "ybm_aeon_pg_branch" "feature" {
  cluster_name   = ybm_aeon_pg_cluster.example.cluster_name
  cluster_id     = ybm_aeon_pg_cluster.example.cluster_id
  branch_name    = "feature"
  parent_branch  = ybm_aeon_pg_branch.dev.branch_name
  fork_point_lsn = "0/16B3748"
}

# A branch of a cluster in a BYOC environment
resource "ybm_aeon_pg_branch" "byoc_dev" {
  environment_id = ybm_aeon_pg_byoc_cluster.example.environment_id
  storage_pool   = ybm_aeon_pg_byoc_cluster.example.storage_pool
  cluster_name   = ybm_aeon_pg_byoc_cluster.example.cluster_name
  cluster_id     = ybm_aeon_pg_byoc_cluster.example.cluster_id
  branch_name    = "dev"
}
```

## Schema

### Required

- `branch_name` (String) The name of the branch. The default branch, main, is created with the cluster and cannot be managed here; set its settings with the cluster's branch_pg_settings and branch_extensions. Changing it forces a new branch.
- `cluster_name` (String) The name of the cluster. Changing it forces a replacement.

### Optional

- `cluster_id` (String) The ID of the cluster. Set it to the cluster resource's cluster_id so that replacing the cluster, which deletes its branches and endpoints, replaces this resource too. Read from the cluster when unset. Changing it forces a replacement.
- `environment_id` (String) The ID of the BYOC environment the cluster is in. Leave it unset for a shared cluster (ybm_aeon_pg_cluster). Changing it forces a replacement.
- `extensions` (Set of String) Extensions to install in the branch. Extensions can be added in place but not removed.
- `force_destroy` (Boolean) Whether destroying or replacing the branch may also delete its endpoints and the branches forked from it. Without it, deleting a branch that still has them fails. Defaults to false. It is read from state, so apply it before the destroy or replacement that needs it.
- `fork_point_lsn` (String) The LSN of the parent branch to fork at, such as 0/16B3748. Defaults to the parent's latest. Changing it forces a new branch.
- `parent_branch` (String) The name of the branch to fork from. Defaults to main. Changing it forces a new branch.
- `pg_settings` (Map of String) PostgreSQL settings of the branch, such as work_mem. They apply to every endpoint on the branch; an endpoint's own pg_settings override them. Can be changed in place. Leave it unset to leave the settings as they are, such as those a fork inherits from its parent; set it to {} to clear them. Removing a key resets the setting: an endpoint setting falls back to its branch's value, and a branch setting to the PostgreSQL default.
- `storage_pool` (String) The storage pool of the BYOC cluster. Required with environment_id, and not allowed without it. Changing it forces a replacement.
- `ttl` (String) Reserved for deleting the branch automatically after a duration, such as 24h. Not supported yet.

### Read-Only

- `account_id` (String) The ID of the account the cluster belongs to.
- `branch_id` (String) The ID of the branch.
- `state` (String) The state the branch last reported.

## Import

Import is supported using the following syntax:

```shell
# A branch of a shared cluster is imported by <cluster_name>/<branch_name>
terraform import ybm_aeon_pg_branch.dev orders/dev

# A branch of a BYOC cluster is imported by <environment_id>/<storage_pool>/<cluster_name>/<branch_name>
terraform import ybm_aeon_pg_branch.byoc_dev acme-prod/payments/orders/dev
```
